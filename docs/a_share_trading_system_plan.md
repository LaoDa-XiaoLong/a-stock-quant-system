# A股交易系统构建计划

## 📋 项目概述

基于老大提出的核心问题："为什么财报超预期但股价下跌？"，我们启动A股多因子交易系统构建项目。目标是从单一财报分析升级到五维综合分析，构建适合A股当前阶段的交易系统。

## 🔍 核心问题分析

### 顺丰控股案例研究
**现象**: 2025Q4季报营收超预期3481.3%，净利润超预期1604.7%，但财报后股价下跌14.3%

**根本原因**: 单一维度（财报）分析不足以预测股价走势

**五维分析框架**:
```
股价走势 = α×基本面 + β×技术面 + γ×资金面 + δ×情绪面 + ε×风险面
```

## 📊 五维因子体系

### 1. 基本面因子（30%权重）
- **财报质量**: 营收/利润增长率、毛利率、现金流
- **估值水平**: PE/PB分位数、PEG比率、股息率
- **成长性**: 3年复合增长率、行业地位

### 2. 技术面因子（25%权重）
- **趋势判断**: 均线系统、趋势强度、突破信号
- **动量分析**: RSI、MACD、成交量配合
- **波动度量**: ATR、布林带位置

### 3. 资金面因子（20%权重）
- **主力资金**: 北向资金、融资融券、大宗交易
- **成交量**: 量价关系、换手率、资金流入流出
- **持仓结构**: 机构持仓、散户持仓

### 4. 情绪面因子（15%权重）
- **市场情绪**: 板块轮动、涨停板数量、媒体舆情
- **投资者情绪**: 新增开户数、基金仓位、期权PCR
- **社交媒体**: 股吧、微博、财经新闻情感分析

### 5. 风险控制因子（10%权重）
- **系统性风险**: 市场波动率、股债性价比、汇率
- **个股风险**: 流动性、财务风险、事件风险
- **组合风险**: 相关性、集中度、最大回撤

## 💡 创新点

### 1. 主力意图揣测模型
- **大数据分析**: 龙虎榜、大宗交易、股东变化
- **行为模式识别**: 机构操作习惯分析
- **资金流向预测**: 基于历史模式的预测

### 2. 动态权重调整
- **市场状态识别**: 牛市/熊市/震荡市自适应
- **因子轮动**: 不同环境下最优因子选择
- **机器学习优化**: 基于历史表现动态调整

### 3. 情绪量化系统
- **文本挖掘**: 财经新闻情感分析
- **社交媒体监控**: 实时情绪指数
- **搜索热度分析**: 百度指数、微信指数

### 4. 风险预警系统
- **黑天鹅预警**: 极端事件监测
- **流动性预警**: 成交异常监测
- **财务预警**: 财报质量实时监控

## 📈 预期绩效目标

### 绝对收益
- **年化收益率**: 15-25%
- **最大回撤**: <20%
- **夏普比率**: >1.0
- **胜率**: >55%

### 相对收益
- **超额收益**: 年化8-15%（vs 沪深300）
- **信息比率**: >0.5
- **跟踪误差**: <8%

## 🛡️ 风险控制体系

### 事前风控
- **股票池筛选**: 基本面+流动性+合规性
- **仓位限制**: 单股≤5%，行业≤20%
- **杠杆限制**: 无杠杆或低杠杆

### 事中风控
- **实时监控**: 价格异常、成交量异常
- **止损机制**: 个股止损、组合止损
- **流动性管理**: 冲击成本控制

### 事后风控
- **绩效归因**: 收益来源分析
- **风险归因**: 风险来源分析
- **策略评估**: 持续优化改进
