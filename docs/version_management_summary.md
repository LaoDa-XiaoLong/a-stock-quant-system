## 🔧 版本管理工具使用指南

### 基本命令

#### 1. 列出版本
```bash
# 列出所有版本
python3 scripts/simple_version_manager.py list

# 列出特定类别
python3 scripts/simple_version_manager.py list stock_models

# 列出具体项目
python3 scripts/simple_version_manager.py list report_templates financial_daily
```

#### 2. 创建新版本
```bash
# 创建新版本
python3 scripts/simple_version_manager.py create <类别> <项目> <版本号> <源文件路径>

# 示例：创建选股策略v1.1
python3 scripts/simple_version_manager.py create stock_models stock_selection v1.1 strategies/stock_pool_filter_fixed.py
```

#### 3. 切换版本
```bash
# 切换版本
python3 scripts/simple_version_manager.py switch <类别> <项目> <版本号>

# 示例：切换回财报监控日报v2.0
python3 scripts/simple_version_manager.py switch report_templates financial_daily v2.0
```

#### 4. 验证版本
```bash
# 查看当前版本
python3 scripts/version_aware_executor.py
```

## 🎯 解决的核心问题

### 问题1：避免"倒车"现象
**解决方案**：版本管理系统确保：
- 每个重要变更都有版本记录
- 不满意时可以一键回滚
- 版本对比帮助评估改进效果

### 问题2：股票模型评估困难
**解决方案**：
- 每个策略版本都有独立目录
- 可以保存性能数据和回测结果
- 方便对比不同版本的表现

### 问题3：系统复杂度控制
**解决方案**：
- **核心优先**：只对股票相关模型强制版本化
- **渐进实施**：其他功能可选版本化
- **工具简化**：提供简单易用的CLI工具

## 🚨 风险控制措施

### 技术风险控制
1. **版本冲突**：依赖隔离，独立环境
2. **数据一致性**：版本化数据迁移脚本
3. **性能影响**：渐进实施，监控优化

### 业务风险控制
1. **错误版本上线**：严格测试，灰度发布
2. **回滚失败**：多版本保留，定期备份
3. **版本混乱**：版本清理策略，归档机制

### 操作风险控制
1. **误操作**：操作确认，权限控制
2. **版本丢失**：多重备份，版本同步
3. **工具故障**：备用方案，手动恢复
